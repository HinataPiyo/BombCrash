# BombCrash ゲーム説明書

## 1. ゲームの概要

「BombCrash」は、次々と湧いてくるカウントダウン爆弾(敵)を、強力な凍結爆弾で破壊する爽快アクションゲームです。

プレイヤーはキャラクターを操作し、敵を倒してスクラップを入手します。  
このスクラップでスキルや装備を強化できます。  

このゲームでは、Wave(波)の概念を採用しており、Wave数が上がるにつれ敵が強くなっていくようになっています。

## 3. 操作方法

このゲームは、キーボードで操作します。

| アクション | キーボード |
| :--- | :--- |
| **移動**      | LeftArrow キー, RightArrow キー|
| **照準**      | UpArrow キー, DownArrow キー|
| **爆弾投擲**  | Space キー |
| **スキル 1** | Z キー |
| **スキル 2** | X キー |
| **スキル 3** | C キー |
| **必殺技**   | V キー |

## 4. ゲームの流れ

1.  **ホーム画面**
    | 名前 | 概要 |
    | :--- | :--- |
    | **出撃**      | カウントダウンボムを撲滅しに行きます |
    | **プレイヤー**| プレイヤー関連の内容がまとめてあります |
    | **オトモ**    | オトモ関連の内容がまとめてあります |
    | **ガチャ**    | スキルのガチャが引けます |

2.  **ゲームプレイ**
    - 画面上に表示される敵を、ボムを投げてすべて倒します。
    - フィールド上の敵をすべて倒すと次のウェーブに行きます。
    - 敵のカウントダウンが0になると大爆発してGameOverになります。
    - 敵を倒すと、スクラップが手に入ります。
    - 左下のスキル（Z,X,Cで発動）を使用できます。
    - 真ん中下のバーは必殺技です。（Vで発動）
    - 上記の少し上にある爆弾のイラストは、爆弾の所持数です。

3.  **リザルト画面**
    - ゲームオーバーになると、リザルト画面が表示されます。
    - `InsightPoint(知見ポイント)`は、Wave数に応じて獲得数が決まります。
    - `Scrap(スクラップ)`は、敵を倒したときに得られるリソースです。

## 5. 主な登場キャラクター・アイテム

- **プレイヤー**: あなたが操作する主人公。
- **凍結爆弾**: 通常の攻撃手段。様々な種類があります。
- **オトモ**: プレイヤーと一緒に戦ってくれる頼もしい仲間。
- **敵**: カウントダウンが0になるとGameOverになります
- **スタンピード**: 10waveごとに大量に敵が出現します。
- **スキル**: 一定時間ごとに使用できる強力な特殊攻撃。(ガチャで同じスキルが出れば、insightPoint(IP)で覚醒で覚醒できます)
- **装備**: プレイヤーの能力値を上昇させるアイテムです。(スクラップで購入可能)
- **スキル**: プレイヤーの能力値を上昇させるアイテムです。(スクラップで購入可能)
- **InsightPoint(知見ポイント, IP)**: Wave進行度に応じて獲得数が決まります。
- **Scrap(スクラップ)**: 敵を倒したときに得られるリソースです。
