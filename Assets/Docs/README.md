# BombCrash ゲーム説明書

ゲーム全体の概要と設計は [開発・設計ドキュメント](documentation.md)、物語は [あらすじ](story.md) を参照してください。

## 1. ゲームの概要

「BombCrash」は、カウントダウンで爆発する敵性爆弾を、プレイヤーが投げる凍結爆弾で撃破するウェーブ制アクションゲームです。敵を倒してスクラップを集め、装備やスキルを活用しながら、より先のウェーブを目指します。

敵はそれぞれHPとカウントダウンを持ちます。カウントが0になると爆発してゲームオーバーになるため、敵を爆発前に倒してください。

## 2. ホーム画面・ゲームの流れ

ホーム画面から出撃やプレイヤー・オトモ関連の画面へ移動できます。ガチャ画面のボタンは未実装部分があるため、現在は無効化されています。

1. 出撃してゲームを開始します。
2. ウェーブ中に出現する敵を爆弾や装備スキルで倒します。
3. ウェーブの敵出現が終わった後、フィールド上の敵がいなくなると次のウェーブへ進みます。
4. 敵を倒すとスクラップを獲得します。ゲームオーバー後はリザルトで到達ウェーブや獲得資源を確認できます。

一定間隔で大量の敵が出現するスタンピードや、ボスの出現も設定されています。ウェーブが進むほど敵の出現やステータスが変化します。

## 3. 操作方法

| アクション | 操作 |
| --- | --- |
| 左右移動 | ← / → |
| 爆弾の着弾位置を上下に調整 | ↑ / ↓ |
| 爆弾を投げる | Space |
| 装備スキル 1 / 2 / 3 | Z / X / C |
| 必殺技（使用可能時） | V |
| ゲームオーバー演出後にホームへ戻る | Space |
| ホーム画面などの UI 操作 | マウスクリック |

爆弾は所持数に上限があり、時間経過で補充されます。スキルや必殺技はクールタイム・使用可能状態に従います。スキルの自動発動は装備スキルの設定により異なります。

## 4. 主な要素

- **プレイヤー**：左右に移動し、爆弾を投げて敵を攻撃します。
- **敵性爆弾**：カウントダウンが尽きる前に撃破する必要があります。敵の種類やウェーブに応じてHPなどが異なります。
- **スタンピード**：一定間隔で発生する敵の大量出現ウェーブです。
- **オトモとスキル**：オトモにスキルを装備して出撃できます。スキルはキー操作または個別設定による自動発動で使用します。
- **装備**：スクラップを使った購入・強化で、プレイヤーの能力を補助します。
- **スクラップ**：敵を倒すと獲得でき、装備などに使用するゲーム内資源です。
- **知見ポイント（IP）**：ウェーブの到達状況などに応じてリザルトで獲得する資源です。

## 5. 現在の制限

- ガチャ機能は未実装部分があるため、ホーム画面のガチャボタンが無効化されています。現状ではスキルガチャを利用できません。
- このリポジトリには Unity プロジェクトが含まれますが、配布用の実行ファイルや公開ダウンロード先は記載されていません。

## 6. ダウンロード・起動

プロジェクトから起動する場合は、リポジトリを取得して Unity Hub からプロジェクトを追加し、**Unity 6 (6000.0.29f1)** で開いてください。Unity Editor 上でシーンを実行します。配布用ビルドが公開されている場合は、別途案内された配布元から入手してください。
