# BombCrash

カウントダウン爆弾の敵を凍結爆弾で撃破し、押し寄せるウェーブを生き延びる2Dアクションゲームです。Unityプロジェクト一式と、ゲームの概要・設計・操作方法をまとめています。

## 1. 作品名・概要

**BombCrash** は、プレイヤーが爆弾を投げて敵を倒しながら、次々と強くなるウェーブに挑むアクションゲームです。敵はそれぞれカウントダウンを持ち、時間切れになると爆発してゲームオーバーになります。敵を凍結爆弾で倒し、爆発前にフィールドを制圧することが基本の遊びです。

物語では、父の失踪と謎の敵性爆弾の出現をきっかけに、主人公が自ら開発した凍結爆弾を手に戦いへ向かいます。詳しいあらすじは [story.md](Assets/Docs/story.md) を参照してください。

## 3. ゲームの特徴・主要機能

- **カウントダウン爆弾との戦闘**：敵のHPを削り、カウントが尽きる前に撃破します。敵を倒すとスクラップを獲得できます。
- **ウェーブ進行**：ルールアセットに基づき敵の種類や出現比率、出現間隔を変化させます。定期的なスタンピードも設定されています。
- **爆弾の照準と補充**：上下キーで着弾位置を調整し、所持数の範囲内で爆弾を投げます。爆弾は時間経過で補充されます。
- **スキル・必殺技**：装備したオトモスキルと必殺技を、クールタイムや使用可能状態に応じて発動できます。スキルは設定に応じて自動発動するものもあります。
- **育成とリザルト**：スクラップや知見ポイントを使う装備・成長要素があり、ゲーム終了時に到達ウェーブや獲得資源を確認できます。
- **ホーム画面と演出**：ホーム画面で各種パネルを操作し、フェードやカットイン、サウンド、画面振動を交えたゲーム進行を行います。

ガチャ画面のボタンは、未実装部分があるため現行プロジェクトでは無効化されています。利用できる機能と操作の詳細は [ゲーム説明書](Assets/Docs/README.md) を参照してください。

## 4. 技術的な工夫・設計

- **ScriptableObject によるデータ管理**：プレイヤー・敵・ボスのステータス、爆弾、スキル、装備、ウェーブルールなどをアセットとして分離し、数値や出現設定を調整しやすくしています。
- **ルールからのウェーブ生成**：`WaveGenerator` が `EndlessWaveRule` と敵ごとの出現パターンを使い、ウェーブの時間・出現間隔・敵候補を生成します。
- **役割ごとのスクリプト分割**：`System` が戦闘や進行、`UI` が表示や画面操作、`SO` がゲームデータを担当します。`IEnemy` などのインターフェースで敵の共通処理を扱います。
- **シーン遷移と進行演出**：ホーム・ゲーム・ストーリーなどのシーンを用意し、ローディングシーンを介した遷移やカットインを組み合わせています。

詳細は [スクリプト設計ドキュメント](Assets/Docs/documentation.md) にまとめています。

## 5. 工夫した点・課題と改善

データと処理を分けたことで、敵やウェーブの調整をコード変更に限定せず、Unity 上のアセット編集で行える構成にしています。また、コミット履歴では UI の大幅な見直し、削除済みアセット参照の修正、ホーム画面への操作案内追加、装備スロットアニメーションの初期化など、画面と進行の改善が段階的に行われています。

一方、直近のコミット（`87f710b`）では、未実装部分があるためホーム画面のガチャボタンを無効化しています。ガチャを再び利用可能にするには、抽選から結果表示・所持品反映までの一連の動作を確認し、画面表示やデータとの整合性を仕上げる必要があります。公開用ビルドの配布先もこのリポジトリには記載されていません。

## 6. 操作方法・ダウンロード

| 操作 | キー |
| --- | --- |
| 左右移動 | ← / → |
| 爆弾の着弾位置を上下に調整 | ↑ / ↓ |
| 爆弾を投げる | Space |
| 装備スキル 1 / 2 / 3 | Z / X / C |
| 必殺技（使用可能時） | V |
| ゲームオーバー演出後にホームへ戻る | Space |
| ホーム画面などの UI 操作 | マウスクリック |
